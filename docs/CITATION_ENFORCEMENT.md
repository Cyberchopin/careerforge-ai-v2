# Gemini audit claim boundary

The existing `/api/gemini-audit` path already used Gemini, bounded evidence excerpts, structured output, evidence-ID range checks, SHA-256 input digest, and a Cloud Run/Secret Manager deployment script. This change adds a separate post-generation gate.

For each proposed `verifiedStrength` (maximum four), the gate resolves its cited IDs to the exact excerpts supplied in the request. A second call to the **same Gemini model** receives only the proposed claim and those cited excerpts, not the first call's verdict. It must return `supported`, `partial`, or `unsupported` in a runtime-validated structure. Only `supported` survives. Missing/duplicate/out-of-range citations, malformed generator or judge output, and judge failures fail closed. Rejected strengths are not shown as verified strengths; the audit verdict reports withholding. The API now returns SHA-256 digests for both normalized input and final displayed audit output. These are reproducibility receipts, **not signatures or proof of factual truth**.

The candidate-strength output is checked with Zod at runtime, after generation. `npm run test:audit` covers malformed outputs, unknown and non-entailing citations, judge failure, and the two-call production route. The existing rendered-route tests cover the worker bundle. Both switches can later be isolated for evaluation, but this production endpoint intentionally has no user-accessible bypass.

Limits: this is a **second-pass model-based consistency check**, not independent verification or human ground truth. It can still be wrong. This does not validate the deterministic ProofGraph, ATS score, or every free-text recommendation. It adds up to four extra model calls per uncached audit, so the Cloud Run request timeout is 90 seconds and real latency/cost must be measured before claiming an improvement. **As of September 17, 2026, this gate is code-reviewed and locally tested but not deployed to the public Cloud Run service.** Do not send sensitive resumes without user consent and an appropriate privacy review.
